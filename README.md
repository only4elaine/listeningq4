# N2 即时应答 · 真题特训

JLPT N2 听解「問題4 即時応答」专项练习，纯静态页面（无需构建），风格与 [riyukaoshi](https://only4elaine.github.io/riyukaoshi/) 保持一致。

## 练习方式（按真题）
1. 先听：题目只播放一遍，不显示任何文字（真题模式，可在首页设置里关闭）。
2. 选 1 / 2 / 3（键盘 1 2 3 也可以），立即判分。
3. 选完才显示：日文原文、中文译文、简短解说、正确答案。
4. 最后自评「听懂了 / 没听懂」，没听懂（以及答错）的题进入「重听」，按 1→2→4→7→15 天间隔再出现。

进度保存在浏览器本地（localStorage），可在首页「设置与数据」里导出或清除。

## 内容
- 2015.7 – 2026.7，共 22 套（2020.7 因疫情取消，没有真题）。
- 每套 11–12 题，录音已按题切好（`audio/<卷>/4-<题号>.mp3`）。
- 数据在 `data.js`，每题含：原文、选项、答案、译文、解说，以及答案/译文的来源标记。
- 页面里的「抽查清单」列出了哪些答案、译文来自真题 PDF，哪些是 AI 判断/翻译，建议重点抽查后者。
